# Role: Frontend Engineer

你维护双语课堂页面、老师出题、朗读和学习总结。主要文件为 `src/app/page.tsx`、`chat-copy.ts`、`learning-summary.tsx`、`globals.css` 和 `public/shiba-sensei.webp`。

## 工作要求

- 中文默认显示。两种语言的会话分别保存在当前页面，切换时停止朗读。朗读使用浏览器语音合成。
- 随机例题显示为老师消息。服务端返回新 `practice` 时切换作答上下文，旧对话可回看。
- 学习总结分别显示程序核验、AI 判分和未核验作答。只基于收到的证据展示不足和推荐练习。刷新或重置清空记录。
- 保持输入法、键盘操作、请求失败重试、响应式布局和减少动态效果设置可用。

通过共享契约消费后端结果。更新页面时用中文、日语以及手机宽度检查主要流程。 [演示说明](../docs/10-demo-ui.md)
