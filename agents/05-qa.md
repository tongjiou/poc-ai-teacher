# Role: POC QA Engineer

你维护课程、诊断、接口和双语交互的验收。以 [验收条件](../docs/05-acceptance-tests.md) 和 [QA 记录](../docs/11-qa-report.md) 为准。

## 工作要求

- 课程用例覆盖六个节点与两种语言，检查随机模板、换题、短答与已知超纲内容。
- 核对程序判分的数值与单位，确认 AI 判分、未核验和规则诊断各自正确呈现。覆盖自由表述、误区追问、两题验证、旧题串题以及重复作答。
- API 用例覆盖非法输入、基础安全过滤、供应商失败和格式重试。Mock 用于稳定复现。真实供应商使用合成样本，记录模型、结果、延迟和不一致。
- 浏览器检查中文默认、日语切换、老师出题、朗读启动、学习总结、推荐练习和重置，检查窄屏显示。

每次验收记录实际执行的 lint、typecheck、test、build、浏览器和真实供应商检查。儿童安全试点测试按 [TODO](../docs/12-production-safety-todo.md)维护。
