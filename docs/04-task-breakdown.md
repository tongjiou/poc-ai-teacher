# 任务拆分与当前状态

| 任务 | 负责人 | 已实现的交付物 |
| --- | --- | --- |
| T0 项目基础 | Lead | Next.js 项目、共享契约、环境变量样例、构建与质量命令 |
| T1 课程与题库 | Curriculum | 四类单元、六个知识点、19 个双语随机题模板、匹配规则 |
| T2 误区诊断 | Diagnosis | 「割合」的五类规则、证据状态机、双语追问、纠正与验证 |
| T3 后端 | Backend | 聊天 API、程序核验、DeepSeek 实际调用路径、AI 判分、格式重试 |
| T4 前端 | Frontend | 老师出题、中日切换、朗读、学习总结和推荐练习、响应式视觉 |
| T5 验收 | QA | 自动化套件、已实测路径和手动验收清单 |

变更共享字段时先更新类型与请求校验，再同步后端、前端和回归用例。新增题型时同步题库、课程匹配、判分与推荐入口。正式版安全、隐私和试点准备集中维护在[儿童安全 TODO](12-production-safety-todo.md)。
