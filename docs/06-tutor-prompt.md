# 产品运行时提示词

教学系统提示词原文位于 `src/lib/tutor-prompt.ts`。运行时的上下文、开放判分和格式重试指令在 `src/lib/tutor.ts`。

| 路径 | 当前提示词与输出 |
| --- | --- |
| P1 教学 | 扮演日本小学五年级算术老师，沿用当前题目数字与算式，适龄、简短、提示优先，每轮最多一个核心问题。服务端指定教学动作、课程目标和前置知识。中文模式追加简体中文指令。要求返回 `replyJa` |
| P2 教学与判分 | 在同一次请求中附加英文判分指令。先独立解题，再对照最近相关的老师问题与学生答案，接受等价答案。输出 `replyJa` 与 `assessment.verdict`、`assessment.reason`。四类判定包含无法判分 |
| P3 纯文本重试 | 格式失败等情况可重试一次。提示词要求用当前语言返回最多 120 字的纯文本；这条路径没有 AI 判分 |

模型请求携带当前练习及最近最多 9 条对话消息。对命中基础危险内容或个人信息规则的消息进行替换。两个请求共用 12 秒超时预算。程序出题、可计算判分、固定诊断追问和学习总结均为本地逻辑。正式版独立输入和输出审核仍在 [TODO](12-production-safety-todo.md)。
