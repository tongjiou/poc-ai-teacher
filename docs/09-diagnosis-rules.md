# 误区诊断规则说明

诊断使用本地规则与固定中日双语题。规则只将有明确线索的学生发言标记为候选；不会把空白、不确定、普通算式或模型判断当作确认依据。

| 状态或事件 | 处理 |
| --- | --- |
| 当前知识点出现单一、明确的误区线索 | `unknown` → `suspected`，问一道能区分错误原因的题 |
| 诊断题的答案再次表现出同一概念错误 | `suspected` → `confirmed`，先给纠正提示 |
| 学生正确回答诊断题 | 清除概念候选；如果原线索只是计算失误，则进入计算验证，仍不确认概念误区 |
| 诊断题未得到可判定答案 | 保持 `suspected`，继续问同一道题 |
| 两道独立验证题连续答对 | 标记 `resolved`；算错一道会重置连续正答计数 |
| 切换到当前误区不适用的课程节点 | 不把上一题的证据用于新节点 |

`verificationCount` 不存在时，尚未开始验证；`0` 和 `1` 分别等待第一、第二道题；`2` 表示已验证完成。证据记录规则事件（不保留学生原文），最多留最近 12 条，供调试检查。诊断与验证题由代码决定，前端和模型不应改写其数学条件。

目前规则覆盖基准量与比较量颠倒、用加减法求比例、小数转百分数时少乘 10、倍数与百分数混用、计算失误。学习总结按知识点展示已发现的线索，AI 判分单独记录。

## POC 局限

诊断规则只覆盖预设的典型表达。支持数字、常用单位、算式和少量中日短句；长篇自由说明或同时包含多个可能原因的表述可能保持未知。五年级教案中的题目为自编示例。本功能用于演示追问过程，不能据此推断学生整体数学水平。
