# 课程数据与匹配规则

范围参考[日本文部科学省小学算术课程解说](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)。课程目标及前置知识放在 `src/data/curriculum.json`，例题为原创。

| 单元 | 节点 | 双语题模板 |
| --- | --- | --- |
| 割合 | meaning、relation、percent | 11 种，含倍数比较、班级参与率、基准量、折扣和百分数互换 |
| 小数乘除法 | decimal | 2 种，小数乘法、除法 |
| 平面图形面积 | area | 4 种，三角形、平行四边形、梯形和菱形 |
| 立体体积 | volume | 2 种，长方体、正方体 |

`practice.ts` 从预设数值范围取样并组合题干。课程匹配使用符号归一化、中日关键词与当前题目；短答优先关联当前上下文。已知超纲词有明确分支，其他自然语言仍可能匹配不准。误区状态机当前覆盖「割合」，其他单元提供可计算题核验和模型辅导。
