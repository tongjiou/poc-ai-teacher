# 双语课堂演示

1. 在 [本地页面](http://127.0.0.1:3000/) 默认以中文开始。右上角可切换日本語，各自保留当前页面内的会话。
2. 左侧选择随机例题，老师先出题。输入答案，按 Enter 发送。Shift + Enter 换行。「再来一个」会在当前主题出新题。
3. 点击老师回复下的「朗读」可听取当前语言。音色由设备提供，切换语言停止当前朗读。
4. 聊天区下方是「学习总结与辅导向导」。它分别展示程序核验、AI 判分和未核验作答，并提供推荐练习。刷新或重置会清空相应会话记录。
5. 验证误区诊断时手动输入「0.25 是 2.5% 吗？」，依次答 `3%`、`我明白了`、`40%`、`8%`，在不足点分析查看对应状态。

界面使用日式练习册配色、柴犬插画和主题图标，支持手机布局和系统「减少动态效果」设置。
