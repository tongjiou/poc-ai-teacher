# 正式版儿童安全 TODO

当前 POC 通过服务端的中日文关键词和格式规则识别部分危险内容与个人信息。命中时给出固定回应，调用教学模型前也会过滤命中的历史消息。模型回复主要校验格式和长度。以下事项均待实现或确认，面向日本小学五年级学生的正式版与学校试点。

## 第一阶段 · 先让本地练习可独立使用

- [ ] **S01 · 分开本地练习和开放聊天。** 提供题库出题、规则判分和审核过的固定讲解。开放聊天可单独启用和关闭。验收时关闭模型与审核服务，确认练习仍可完成，页面提示当前可用的功能。
- [ ] **S02 · 在调用外部服务前检查个人信息。** 保留现有规则，并增加中日文个人信息识别，覆盖姓名、学校、住址、电话、邮箱等。根据识别结果提示改写或替换敏感片段，再按需要传递当前题目和最少量的答题上下文。用模拟姓名、无标签号码和包含相似数字的正常数学题验收，并检查请求与日志中实际出现的数据。

## 第二阶段 · 开放聊天进入学校试点前

- [ ] **S03 · 增加独立的输入审核。** 覆盖明确危险请求、隐晦表达和多轮语境。保留高置信关键词规则，增加能区分正常课堂引用、危险操作请求和可能遇险的审核能力。审核不通过或不可用时，按规则返回安全回应或切换到本地练习。
- [ ] **S04 · 按风险选择回应。** 由产品规则选择继续教学、提示改写、暂停辅导或使用事先审核过的安全回应。涉及孩子可能遇险时，用适龄措辞引导联系身边可信任的成人。中日文回应由具备儿童安全经验的人员审核。学校试点前明确人工接手的触发条件、负责人、可用时段和可见信息；分别验证有人接手及无人接手的情况。
- [ ] **S05 · 在显示和朗读前审核模型输出。** 检查危险操作细节、索要个人信息和其他不适龄内容。发现风险时，替换为审核过的回应。模拟审核超时、报错及模型供应商返回内容过滤结果，确认原回复不会显示或朗读，也不会把内容过滤当作格式错误重试。
- [ ] **S06 · 核对日本试点的数据处理安排。** 记录教学模型和审核供应商各自收到的字段、数据处理地点、留存期限、训练用途及删除机制。结合学校与供应商合同，确认监护人告知、同意及跨境处理安排的适用要求。由负责隐私合规的人员在试点前确认并留档。
- [ ] **S07 · 建立中日文验收集和试点条件。** 使用合成样例覆盖谐音、分字、隐晦表达、多轮暗示、正常课堂讨论、个人信息及审核故障。分别记录漏拦、误拦和响应延迟，在试点前约定可接受的结果与必须修复的失败场景。通过验收后，先在有教师参与的小范围试点开启开放聊天。

## 第三阶段 · 试点与上线后的运营

- [ ] **S08 · 建立安全事件处理和回归机制。** 提供问题反馈入口，记录必要的事件类别和处理结果。明确原始对话的访问权限、保留期限和删除方式。把漏拦与误拦转成脱敏回归案例，在更新模型、审核策略或提示词后重跑。
- [ ] **S09 · 验证暂停与恢复流程。** 遇到严重漏拦或审核异常时，值班负责人可关闭开放聊天并保留本地练习。记录触发原因、修复结果和恢复决定。用模拟事件演练一次。

参考资料包括 [UNICEF 儿童 AI 指南](https://www.unicef.org/innocenti/reports/policy-guidance-ai-children)、[NIST 生成式 AI 风险管理指南](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf) 和 [日本个人信息保护委员会指南](https://www.ppc.go.jp/personalinfo/legal/guidelines_tsusoku/)。
