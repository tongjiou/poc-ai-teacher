# 验收测试

| 场景 | 验收条件 |
| --- | --- |
| 双语随机出题 | 中文默认显示，可切换日语。六个入口由老师出题，同一入口连续抽题不完全重复 |
| 课程感知 | 自然提问及题库题分别路由到对应节点。简短作答保留当前题目 |
| 换题与判分 | 「再来一个」后按新题判分。旧对话可回看。面积与体积题核对数值和填写的单位 |
| 误区验证 | 首错只标记疑似。有证据才确认，连续两道验证题答对才标记已纠正 |
| 开放式答案 | 有明确作答对象时模型可返回正确、部分正确、错误及理由。无法判断时不计正确数 |
| 学习总结 | 规则核验、AI 判分、暂未核验分别展示，推荐按钮可开一道练习 |
| 工程与失败 | 无密钥可运行 Mock。非法请求可解释，模型失败可重试。Lint、类型检查、测试、生产构建通过 |
| 基础安全 | 关键词及格式规则命中时使用本地回应，命中的历史消息向供应商发送前替换 |

试点前另外执行[儿童安全 TODO](12-production-safety-todo.md)中的双语安全验收。课堂效果、儿童隐私和正式版安全审核与上述功能验收分开评估。
